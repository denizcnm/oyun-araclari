Understanding Rainbow Six Siege sensitivity

Rainbow Six Siege uses separate sensitivity behavior for hip-fire and aiming down sights, with additional scope magnification options. A converted hip-fire value should not be assumed to match every ADS optic. Use the calculator as a baseline, then review the in-game ADS and per-scope settings and test each magnification you regularly use.

  4. Test the suggested value in a practice area or a low-pressure match.

Conversions are estimates for a useful starting point. Field of view, aspect ratio, input settings and game-specific aiming systems can affect the final feel.

What are DPI and eDPI?

DPI describes your mouse's sensitivity setting. eDPI is calculated by multiplying mouse DPI by in-game sensitivity. For example, 800 DPI × 0.5 sensitivity = 400 eDPI.

eDPI is most useful when comparing settings within the same game and under comparable conditions. It is not a universal cross-game measurement, because games can use different camera, input and aiming systems.

How to find a comfortable sensitivity

There is no single best sensitivity for every player. Your mouse, desk space, grip, preferred play style and consistency all matter. Start with a value you can control, practice with it, and make small changes only when you have a clear reason.

Keep mouse DPI consistent while testing. When a game has separate ADS, scope or zoom multipliers, review those settings independently instead of assuming a hip-fire conversion covers every situation.

Rainbow Six Siege Sensitivity FAQ

Does one sensitivity value cover every Siege scope?

No. ADS behavior and magnification settings can differ by optic. A general conversion is only a starting point; check each scope you use.

What is eDPI?

eDPI is mouse DPI multiplied by in-game sensitivity. It is useful for comparing values within a consistent game context, but it does not account for Siege's different ADS magnifications.
